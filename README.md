# LiMao Language Learning

**LiMao** is a data-driven language learning application designed to bridge the gap between intermediate-level study and the consumption of native media like TV shows and books.

Our core philosophy is to make native media more accessible by allowing users to "pre-learn" the most frequent unknown words for a specific piece of content, making the learning process more efficient and rewarding.

## Key Features

  * **Media Vocabulary Analysis**: Get detailed statistics on the vocabulary required for TV shows and books, including total word count and difficulty scores.
  * **Personalized Stats**: See exactly how many words you already know in a piece of media and how many you need to learn to reach comprehension.
  * **Integrated SRS Flashcards**: Instantly create targeted flashcard decks from any media's vocabulary list using an Anki-inspired algorithm.
  * **Community Decks**: Create and share decks for new media or use high-quality decks created by the community.

## Tech Stack

  * **Frontend**: Nuxt.js
  * **Backend/BaaS**: Supabase
  * **NLP Processing Service**: Python with FastAPI
